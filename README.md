# WebADB 控制台 · Android 客户端 (APK)

基于 [WebADB 控制台](https://github.com/aoooa101/aoooa-webadb) 的 Android 应用打包项目。

## 目标

- 将网页版 WebADB 控制台打包为 Android App
- 内置支持 WebUSB 的内核（GeckoView / 定制 WebView）
- 通过 GitHub Actions 云端编译，免本地 Android Studio
- 签名 APK 通过 GitHub Release 分发
